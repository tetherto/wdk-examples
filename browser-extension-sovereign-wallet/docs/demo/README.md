# Demo video

The full demo video (~60s) is hosted in the canonical repository to keep this examples clone lightweight:

**https://github.com/001453/Sovereign-wallet/tree/main/wdk-extension/docs/demo**

After cloning Sovereign-wallet, open `wdk-extension/docs/demo/index.html` locally to play the MP4 in-browser.

## What the demo shows

1. Create a new wallet (mnemonic + password)
2. Unlock and view multi-chain portfolio (EVM, Bitcoin, Solana)
3. Send native asset on EVM
4. Receive flow with QR code
5. dApp provider (`window.wdk`) origin gating

Screenshots are included in [../screenshots/](../screenshots/) for quick review in the PR.
